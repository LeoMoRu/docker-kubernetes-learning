=== Preguntas ===
Que PID tiene el proceso init o system?
el proceso init o systemd siempre tiene el PID 1 "Process ID 1", ya que es el primer proceso que arranca el sistema operativo en el espacio de usuario al iniciar el equipo.

Que significa el puerto :22 si aparece? 
este es el puerto estandar para el protocolo SSH"Secure Shell" si nos aparece abierto significa que esta listo para aceptar conexiones remotas seguras de administracion a traves de SSH.

por que es importante que un contenedor no corra como root?
es fundamental por razones de seguridad y aislamiento. si un proceso dentro de un contenedor se ejecuta con privilegios de usuario root y llegara a presentarse una vulnerabilidad o un escape del contenedor "countainer breakout", el atacante obtendria acceso de root directamente al sistema operativo de host fisico, coprometiendo toda la maquina. Correr como un usuario sin privilegios limita el radio de accion de cualquier brecha de seguridad.
